# 📝 TaskFlow - Flask To-Do App

A modern To-Do application built with Flask, SQLite, HTML, CSS and JavaScript.

## 🚀 Features

* User Registration & Login
* Secure Password Hashing
* Add New Tasks
* Edit Existing Tasks
* Delete Individual Tasks
* Clear All Tasks
* Task Status Management

  * Pending
  * Working
  * Done
* Flash Messages
* Dark Theme UI
* SQLite Database Storage

## 🛠 Tech Stack

* Python
* Flask
* SQLite
* HTML5
* CSS3
* JavaScript
* SQLAlchemy

## ⚙ Installation

1. Create virtual environment

python -m venv .venv

3. Activate virtual environment

Windows:

.venv\Scripts\activate

4. Install dependencies

pip install -r requirements.txt

5. Run application

python run.py

6. Open browser

http://127.0.0.1:5000
